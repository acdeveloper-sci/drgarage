# Chip

Píldora de solo lectura para el estado del auto (`--recibido`, `--proceso`, `--cotizacion`, `--listo`) o de una cotización (`--pendiente`, `--aprobada`, `--rechazada`). No es tocable. En la lista también marca "Esperando aprobación" (pendiente) o una decisión reciente del cliente (menos de 3 horas).
