# Field

Etiqueta encima del campo (`dr-field` envuelve label e input). Campos de `input-height` (56px), texto 18px, borde `line-strong`; al enfocar, borde `ink` y `focus-ring`. Usar el teclado adecuado: `type="tel"` para WhatsApp, `inputmode="numeric"` para costos, `autocapitalize="characters"` para placas. La foto usa `dr-photo` (un label grande con el input oculto) y muestra la vista previa debajo. Los errores van al pie del formulario con `role="alert"`, y el formulario conserva lo escrito.
