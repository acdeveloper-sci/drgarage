# Entradas para las specs de Kiro

| Archivo | Feature | Estado |
| --- | --- | --- |
| `001-seguimiento-por-enlace.md` | Registro, cambio de estado, aviso por WhatsApp y vista pública del cliente | Desplegado |
| `002-cotizaciones.md` | Cotizaciones con aprobación o rechazo del cliente, con criterios de aceptación y métricas de éxito | En curso |

Cada entrada genera su propia spec en `.kiro/specs/<número>-<nombre-del-feature>/` (requirements.md, design.md, tasks.md). La spec de cotizaciones se crea aparte y no reemplaza a la de seguimiento por enlace.

El material de base para cotizaciones está en `docs/especificacion.md` (RF3, RF6 y las decisiones D2–D4, D6).
